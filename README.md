# Gordon Hui — Portfolio

Personal portfolio site built with React + Vite, deployed on Vercel.

## Local Development

```bash
npm install
npm run dev
```

## Deployment

Connected to Vercel for automatic deploys on push to `main`.

## Customization

- **Profile photo:** Replace `public/profile.jpg`
- **Content:** Edit `src/Portfolio.jsx`
- **Contact form:** Powered by Formspree (endpoint configured in Portfolio.jsx)
